# Agent Instructions: Implemented Notes

This folder contains shipped Architecture Decision Records (ADRs) that describe the active architecture, behaviors, and invariants of `immortalwrt-action-builder`.

## Maintenance Rules

1. **Present Tense**: Describe existing code reality in present tense (avoid future tense like "will be implemented").
2. **Synchronized In-Place Updates**: When modifying existing features or architecture, update the corresponding active note in `implemented/` to reflect current facts.
3. **Archival**: When a note is fully superseded or obsolete, move it to `.agents/notes/archived/<class>/` and add the `Archived: YYYY-MM-DD` header line.
4. **Accuracy**: Code references, paths, CLI commands, and configuration schemas mentioned in notes must match the codebase.
